# 神经网络原理 · 交互式教学页

一个**单文件、零依赖、离线可用**的神经网络入门教学页面。所有可视化与神经网络训练都用原生 JavaScript + Canvas 手写，不依赖任何 CDN、框架或后端。

## 怎么打开

双击 `index.html` 即可（推荐 Chrome / Edge / Safari）。或者在终端里：

```bash
open index.html          # macOS
```

## 代码结构

`index.html` 内共 7 个 `<script>` 块：

1. **通用工具**：canvas 高清适配、热力配色、`drawNetwork()` 通用网络示意图渲染器
2. **01–03 节交互**
3. **04 节**损失曲线
4. **05 节**梯度下降（等高线烘焙到离屏 canvas，避免每帧重算）
5. **06 节**反向传播分步推导
6. **MLP 核心**：位于 `/* ==== NN-CORE-BEGIN ==== */` 与 `/* ==== NN-CORE-END ==== */` 之间，**无 DOM 依赖**，可直接抽出来在 Node 里单测
7. **07 节**训练界面

## 质量验证记录

- `node --check`：全部 JS 语法通过
