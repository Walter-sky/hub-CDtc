先看地图：神经网络到底是什么

一句话版本：神经网络就是一个"能自动调参数的函数拟合器"。

你给它一堆输入 x 和对应的答案 y，它内部有一大堆可以拧的旋钮（参数）。训练的过程，就是反复地：

  1. 前向传播：用当前旋钮算一个预测 ŷ；
  2. 算损失：衡量 ŷ 和真实答案 y 差多远；
  3. 反向传播：算出"每个旋钮往哪个方向拧、拧多少能让损失变小"（也就是梯度）；
  4. 梯度下降：真的去拧一下旋钮；
  5. 重复 1–4 成千上万次，损失越来越小，函数就拟合出来了。
整页的骨架就是这一个循环：
输入 x → 网络 f(x; W,b) → 预测 ŷ → 损失 L(ŷ, y) → 梯度 ∇L → 更新 W,b ↺

01

神经元：一切从"加权求和"开始

一个神经元干的事，就是给每个输入打个分（乘权重），加起来，再决定要不要"兴奋"。

z = w₁x₁ + w₂x₂ + b      a = σ(z) = 1 / (1 + e−z)
w = 权重(weight，重要性)　b = 偏置(bias，门槛)　σ = 激活函数　a = 输出(activation)

三个概念，用生活化的说法：

  • 权重 w：这个输入对我有多重要。w 为正 → 它越大我越兴奋；w 为负 → 它越大我越冷静。
  • 偏置 b：我的"起床气"。b 很负 → 必须输入信号足够强我才激活；b 很正 → 我天生就想激活。
  • 激活函数 σ：把任意大小的 z 压到 (0,1)，并把"线性打分"变成"非线性判断"。

从神经元到"层"

一个神经元只能画一条直线。但如果我们并排放很多个神经元，每个看同一组输入、各自画一条线，然后把它们的输出再喂给后面的神经元 —— 组合出来的形状就不再是直线了。这就是 多层感知机（MLP）。

x → 隐藏层 1 → 隐藏层 2 → … → 输出层
"深度"学习 = 隐藏层堆得比较深；"宽度" = 单层神经元个数比较多
02

激活函数：非线性的唯一来源

如果层与层之间不夹一个非线性函数，那堆 100 层和 1 层是等价的 —— 真的，下面有证明。

为什么必须要非线性

假设没有激活函数（等价于 σ(z)=z），两层网络算下来是：

h = W₁x + b₁
ŷ = W₂h + b₂ = W₂(W₁x + b₁) + b₂ = (W₂W₁)x + (W₂b₁ + b₂)

括号里仍然只是一个矩阵和一个向量 —— 还是线性变换。100 层叠起来也是同一个线性函数。所以：
没有非线性 → 再深也只会画直线 → XOR 永远学不会。这就是我们要往每层之间塞一个 σ 的原因。

三个必须知道的结论

  • sigmoid 会"梯度消失"：导数最大只有 0.25，多层连乘（0.25ⁿ）很快就趋近于 0，误差传不回前面的层。所以现代网络隐藏层普遍不用它，只用它做二分类的输出层。
  • ReLU 是默认选择：z>0 时导数恒为 1，梯度不打折，计算还快（就是 max(0,z)）。代价是 z<0 时梯度为 0，神经元可能"死掉" —— LeakyReLU 就是给它留条小缝（slope=0.01）。
  • tanh 比 sigmoid 好一点：输出以 0 为中心，导数最大 1.0。但深层依然会消失。
经验法则 隐藏层用 ReLU（或 tanh），二分类输出层用 sigmoid，多分类输出层用 softmax。本页第 07 节你可以现场切换激活函数，亲手看训练效果的差别。
03

"前向"就是数据从左边流到右边。每一层只做两件事：矩阵乘法 + 激活。

04

损失函数：把"错得多离谱"变成一个数

训练需要方向。方向来自一个标量：损失越小，说明当前参数越好。

二分类的两个选择

均方误差 MSE（回归常用）
L = (ŷ − y)²

二元交叉熵 BCE（分类常用）
L = −[ y·ln(ŷ) + (1−y)·ln(1−ŷ) ]
交叉熵 BCE 均方误差 MSE 竖线 = 你当前的位置

把预测概率拖到和真实答案完全相反的地方，看两条曲线谁涨得更凶。

探针

L_MSE0.010
∂L_BCE/∂ŷ−10.00
∂L_MSE/∂ŷ−0.20

注意看两组梯度的数量级：当模型自信地答错时，交叉熵的梯度会爆炸式变大（10 倍 vs 0.2 倍），而 MSE 几乎躺平。这就是分类任务用交叉熵的核心原因。

为什么交叉熵"惩罚自信的错误"

看 −ln(ŷ) 这一项：当真实 y=1 而你预测 ŷ=0.99 时，损失只有 0.01；但预测 ŷ=0.01 时，损失是 4.6。你对错误的自信程度越高，惩罚越接近无穷大。MSE 在同样情况下最多只到 1，学习信号太弱。

一个漂亮的巧合 Sigmoid 输出层 + 交叉熵组合起来，输出层误差化简成一个极其简洁的形式：δ = ŷ − y。这就是第 06 节要用的东西，也是这个组合成为二分类标配的原因。
05

梯度下降：蒙眼下山

损失函数是一片山地，参数是你站的位置。"梯度"告诉你哪个方向最陡，你朝着下坡方向迈一小步。

w ← w − η · ∂L/∂w
η = 学习率(learning rate，每步迈多大)　∂L/∂w = 梯度(往哪边是上坡)　减号 = 往反方向走

为什么梯度指向"上坡"？一维情形最直观：∂L/∂w > 0 说明 w 变大会让损失变大，所以我们要让 w 变小，也就是减去一个正数。多维时，这一点在所有方向里都是"下降最快"的那个方向。

06

反向传播：链式法则的一次高效复用

反向传播不是新数学，只是"复合函数求导"的链式法则。它聪明的点是：把中间结果存起来复用，一次反向就搞定所有参数的梯度。

链式法则复习

如果 L 依赖于 a，而 a 又依赖于 z，那么：

∂L/∂z = ∂L/∂a · ∂a/∂z  →  ∂L/∂w = ∂L/∂z · ∂z/∂w = ∂L/∂z · a_prev

我们把 ∂L/∂z 记作 δ（误差项）。整个反向传播就是在逐层算 δ，然后 梯度 = δ · 上一层的激活值。

输出层（sigmoid + 交叉熵，前面说过的漂亮巧合）
δ⁽ᴸ⁾ = ŷ − y

隐藏层：把后面的 δ 加权传回来，再乘本层激活的导数
δ⁽ˡ⁾ = ( W⁽ˡ⁺¹⁾ᵀ · δ⁽ˡ⁺¹⁾ ) ⊙ σ′(z⁽ˡ⁾)

有了 δ，梯度随手可得
∂L/∂W⁽ˡ⁾ = δ⁽ˡ⁾ · a⁽ˡ⁻¹⁾ᵀ     ∂L/∂b⁽ˡ⁾ = δ⁽ˡ⁾
⊙ 是逐元素相乘。注意公式里的转置位置：误差是"沿着权重反向流回去"的。

为什么反向传播这么重要 求一个参数的梯度，笨办法是"把它扰动一点点，重新跑一遍前向看损失变化"（数值梯度）。n 个参数就要跑 n+1 次前向。 反向传播只要 1 次前向 + 1 次反向，就拿到全部梯度，计算量和参数个数无关。这是能训练百万/十亿参数模型的前提。

建议按这个顺序做 5 个实验

  2. 调回 8，重训 → 边界开始弯曲，准确率冲到 95%+。你刚刚亲眼看到"宽度带来表达能力"。
  3. 激活函数换 sigmoid，其他不变 → 同样轮数下损失明显掉得更慢（通常是 ReLU 的好几倍）。这就是第 02 节的梯度消失。
  4. 学习率拉到 1.0 → 损失曲线剧烈震荡或直接 nan。回到 0.1 就正常。
  5. 数据集换"双螺旋"，隐藏层试试 4 / 8 / 16 → 体会"任务难度 vs 模型容量"的关系。
关于过拟合 本页数据量小、噪声低，你很难看到过拟合。真实场景里如果训练损失一直降、验证损失开始升，就说明网络在"背答案"了。对策：加正则化（L2 / Dropout）、减小模型、增加数据、早停。

新手最容易踩的 6 个坑

  1. 忘了归一化输入。特征量纲差 100 倍时，损失曲面会变成极细的峡谷，梯度下降寸步难行。先把输入标准化到均值 0、方差 1。
  2. 学习率拍脑袋定太大。损失变成 nan 或上下乱跳，第一反应就该是把 η 除以 10。
  3. 隐藏层用了 sigmoid。换成 ReLU，训练速度和效果通常立刻改善。
  4. 回归任务用了交叉熵、分类任务用了 MSE。看第 04 节的梯度数量级对比就明白为什么不能乱用。
  5. 只看训练准确率。必须留一份验证集，否则你只是在看网络背答案背得多好。
  6. 反向传播写错了却不自知。用数值梯度对一遍（(L(w+ε) − L(w−ε)) / 2ε），差异应在 1e-6 量级。

  • 正则化：L2 权重衰减、Dropout、BatchNorm（它还顺带让训练更稳）。
  • 卷积网络 CNN：利用图像的局部性，用卷积核代替全连接，参数量骤降。
  • 循环网络 / Transformer：处理序列与长距离依赖；注意力机制是当前大模型的基石。
  • 动手复现：用 PyTorch 把第 07 节的实验重写一遍，对比 loss.backward() 和你自己手写的梯度。
最后一句 神经网络没有任何魔法。它不过是一堆乘法加法 + 一个链式法则 + 一个反复下坡的循环。 如果你能把第 05、06 节的公式默写出来，并且解释清楚第 07 节的每一个超参数在干什么，你就已经真正入门了。
